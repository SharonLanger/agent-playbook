# Workflow examples

Use the project interpreter `app/.venv/bin/python`. These folders are independent,
checkout-only CrewAI examples; they do not register application workflows.

- [Concepts](concepts/README.md): the original eight experiments, preserved with their tests.
- [Recipes](recipes/README.md): eight portable patterns for parallel work, routing and bounded loops.

Open any folder's `run.py` in PyCharm or run its absolute path from any directory.
Copy the entire example folder to reuse it with the same installed dependencies.
Application checks, packaging and releases exclude these personal examples.
