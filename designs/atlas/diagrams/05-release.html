05 · Build and launch are different

Developer command and runtime command have separate responsibilities

Tooling

  • • Build, version and verify.
  • • Excluded from installed runtime.

Runtime releases package

  • • Discover and launch built releases.
  • • The folder contains source code.

Generated artifacts

  • • Wheels and metadata live in app/dist/.
  • • They are siblings of src and tests.
